# Android APK

- `AgentReach-1.0.0-debug.apk` — sideloadable Android 8.0+ test build
- `AgentReach-1.0.0-debug.apk.sha256` — integrity checksum

This APK is debug-signed with APK Signature Schemes v1, v2, and v3. It is intended for direct testing, not Play Store distribution. Build and sign with a protected release key before publishing. See [`../android/README.md`](../android/README.md).
